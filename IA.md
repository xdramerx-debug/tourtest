# IA.md — источник правды №7. Информационная архитектура

> Статус: **0.2 (v2)** · Дата: 2026-09-18
> **Одинакова для единого приложения v2.** Дерево экранов — вариант C (полный функционал). Плюс **переключатель темы**: доступен со всех экранов (topnav/tabbar-пикер, горячие клавиши, `?theme=N` query), не является экраном и не меняет глубину.
> Бюджеты навигации: зритель ≤2 кликов с главной до live-лидерборда; игрок ≤1 клик до своей счётокарты; глубина ≤3 уровней; 4+ — только с отдельным обоснованием (сейчас таких нет).

## 1. Дерево экранов

```
/                              Главная (уровень 0)
├── /join                      Присоединение: ввод кода (1)
│   └── /join/[code]           Deep link из QR (2 → сразу анкета игрока)
├── /t/[tid]                   Лобби турнира (1)
│   ├── /t/[tid]/board         LIVE-ЛИДЕРБОРД (2)
│   │   └── ?flight=|?round=|?player=   фильтры/фокус (query, не уровень)
│   ├── /t/[tid]/play          МОЯ СЧЁТОКАРТА (2)
│   │   └── /t/[tid]/play/h/[n]         …/лунка N (3, deep link)
│   └── /t/[tid]/match/[mid]   Экран матча (2, вариант B/C)
├── /p/[pid]                   Профиль игрока (1)
├── /history                   История раундов и турниров (1)
├── /admin                     Админ-панель: дашборд (1, отдельная зона)
│   ├── /admin/tournaments     Список турниров (2)
│   │   ├── /admin/tournaments/new           Мастер создания (3)
│   │   └── /admin/tournaments/[tid]         Управление турниром (3)
│   │       └── (вкладки: участники/флайты/tee times/live-контроль/счёт/аудит/экспорт — вкладки, не уровни)
│   ├── /admin/courses         Поля клуба (2)
│   │   └── /admin/courses/[cid]             Настройка поля: лунки/пар/SI/ти (3)
│   ├── /admin/players         Игроки клуба (2)
│   └── /admin/club            Настройки клуба: бренд/локали/единицы (2)
└── /offline                   Служебная страница «нет сети и нет кэша» (1)
```

Служебное: `/healthz` (SPA вернёт статус приложения), `404` — кастомный с возвратом на главную.

## 2. Таблица роутов и доступа

| Роут | Экран | Роли с доступом | Deep link | Примечание |
|---|---|---|---|---|
| `/` | Главная | все | ✅ | Live-турниры крупно; CTA «Моя карточка» при активной сессии |
| `/join`, `/join/[code]` | Регистрация/вход | гость | ✅ | По коду 6 симв. или QR; анкета ≤2 мин |
| `/t/[tid]` | Лобби турнира | все | ✅ | Формат, расписание, участники, CTA «Live» |
| `/t/[tid]/board` | Live-лидерборд | все | ✅ | SSE; query-параметры фильтров; `?tv=1` — kiosk-режим |
| `/t/[tid]/play` | Счётокарта | игрок, маркер (судья — read) | ✅ | Требует сессию; редирект на `/join?next=…` |
| `/t/[tid]/play/h/[n]` | Лунка N в карте | игрок, маркер | ✅ | n=1..36; валидация по числу лунок |
| `/t/[tid]/match/[mid]` | Экран матча | все (правка — участники/судья) | ✅ | B/C: статус, concede, результат |
| `/p/[pid]` | Профиль игрока | все | ✅ | C — расширенная статистика |
| `/history` | История | игрок (моя), все (архив клуба) | ✅ | A — свои раунды; B/C — + архив турниров |
| `/admin*` | Админка | судья (ограниченно: счёт/аудит), админ клуба | ✅ | Отдельный ленивый чанк; guard по роли |
| `/offline` | Offline fallback | все | — | Только когда нет ни сети, ни кэша |

## 3. Навигационные механики

- **Breadcrumbs** на всех вложенных экранах от уровня 2 (`Главная › Турнир › Лидерборд`); на 375px сворачиваются в «‹ Назад к …» (см. ADAPTIVE.md).
- **Возврат к live-лидерборду одним жестом**: постоянная плавающая кнопка «Live» на `/play`, `/match`, `/p/*` во время живого турнира (позиция — в нижней большепалец-зоне, ADAPTIVE.md §6).
- **Deep links**: все публичные роуты доступны по прямому URL (проверка curl-карты в каждом PR); невалидные id → осмысленный 404 с ссылкой на главную.
- **Сохранение контекста**: фильтры лидерборда и последняя лунка — в query/localStorage; «назад» возвращает в тот же скролл-позицию (scroll restoration).
- **Guard-редиректы**: `play` без сессии → `/join?next=/t/[tid]/play`; после join — возврат на исходный роут без потери лунки (n сохраняется).
- **Таб-бар мобильный** (≤768px): Главная · Live · Моя карта · Профиль — максимум 4 пункта, текущий раздел подсвечен; админка из-под мобильного таб-бара исключена (только быстрые действия/ссылка).
- **Админ-зона**: собственный layout с боковой навигацией на ≥1024px и верхними вкладками на меньших; breadcrumbs внутри админки обязательны.

## 4. Пути с бюджетами (проверяются UX-тестом)

| Персона | Путь | Бюджет |
|---|---|---|
| Зритель → лидерборд | `/` → карточка live-турнира → «Лидерборд» (или прямо «Live» в карточке = 1 клик) | ≤2 клика |
| Игрок → карта | `/` → «Моя карточка» | ≤1 клик (при активной сессии) |
| Игрок → карта (холодный вход) | QR → `/join/[code]` → анкета → карта | ≤3 шага, ≤2 мин |
| Судья → правка счёта | `/admin/tournaments/[tid]` → «Счёт» → игрок/лунка → правка с причиной | ≤4 шага |
| Админ → создание турнира | `/admin` → «Новый турнир» → мастер (курс→формат→гандикап→участники→публикация) | ≤5 мин готовыми данными |
| Маркер → ввод за партнёра | карта → свайп/переключатель на игрока | ≤1 жест |

## 5. Пустые и ошибочные состояния (обязательны на каждом экране)

- Лидерборд до старта: «Турнир начнётся в …» + стартовый лист.
- Нет сети: баннер статуса + «данные на HH:MM»; ввод продолжает работать.
- Очередь sync: индикатор «N действий в очереди» в шапке счётокарты (подробности в USER_FLOWS).
- Пустой турнир (нет участников): понятная заглушка для зрителя; для админа — CTA импорта.
