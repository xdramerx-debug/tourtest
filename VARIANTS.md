# VARIANTS.md — источник правды №3. Три варианта функционала

> Статус: **SUPERSEDED на уровне продукта брифом v2** (2026-09-18). Версия: 0.2.
> v2 заменяет «3 варианта × 5 дизайнов» на **одно приложение со ВСЕМ функционалом варианта C и 5 горячими темами** (см. PRODUCT.md §0).
> Этот файл остаётся **архивным описанием спектра функциональности v1**: набор функций v2 = вариант **C (experimental)** целиком. Матрица v1 продолжает жить как песочница под `/variants/`.
> Иерархия наследования ниже — история v1. На любые противоречия отвечает PRODUCT.md §0.

## Вариант A — `variant-a-core`: ядро live-скоринга

**Миссия:** минималистичный, надёжный, быстрый скоринг, которому клуб доверит чемпионат уже завтра.

| # | Ключевая фича | Содержание |
|---|---|---|
| A1 | Счётокарта игрока | Ввод по лункам ≤5 сек, быстрые клавиши, штрафы/pickup, заметки, маркер-режим |
| A2 | Live-лидерборд | Gross / Net / To par / Thru, SSE-дельты ≤2 с, фильтры флайт/раунд/поиск, hole-by-hole детали |
| A3 | Базовые форматы | **Stroke play (гросс/нетто), Stableford** (+ modified stableford как настройка) |
| A4 | Админка | Турнир ≤5 мин, поле ≤10 мин (9/18/27/36, пар, SI, ти), участники (CSV+ручной), правка счёта, DQ/WD/DNS, аудит |
| A5 | Offline-first + роли | Очередь, идемпотентность, конфликты, индикатор связи; роли: игрок, маркер, судья, админ, зритель |
| A6 | Полевые режимы | «Яркое солнце», тёмная тема, тач-таргеты ≥48px, i18n ru/en |

**Риски:** минимальные — нет сложных форматов; главный риск — качество sync (лечится контрактными тестами).
**Отличие:** эталон надёжности; самый лёгкий бандл и быстрый ввод.
**Целевой сценарий:** турнир выходного дня; детский турнир; любой клуб «впервые с цифровым скорингом».

## Вариант B — `variant-b-tournament`: платформа турниров

**Миссия:** всё из A + полный турнирный контур для клубных чемпионатов, корпоративов и pro-am.

| # | Ключевая фича | Содержание |
|---|---|---|
| B1 | Все форматы | + **match play, scramble, best ball, better ball (fourball), foursome, skins, командный агрегат** (правила — FORMATS.md) |
| B2 | Флайты | Разбивка по HI, границы, авто-балансировка, ручные правки, отдельные лидерборды флайтов |
| B3 | Multi-round | 1–4 раунда, общий зачёт, cut (опционально), гандикап: CH, PH, allowance (full/¾/½/др.) |
| B4 | Команды | Командные зачёты, captain's pick (scramble), капитанская роль |
| B5 | Расписание | Tee times, группы, генератор стартового листа, пейсинг поля |
| B6 | Расширенная админка + зритель | Аудит-фильтры, экспорт CSV/печать, TV-режим, spectator view с live-фидом событий |

**Риски:** сложность match play и тай-брейков (лечится unit-тестами FORMATS-сценариев); рост бандла (лечится code splitting: match/scramble — ленивые модули).
**Отличие:** единственный вариант, который закрывает чемпионат клуба «под ключ».
**Целевой сценарий:** клубный чемпионат 2–3 раунда со флайтами; корпоративный scramble на 100+ гостей.

## Вариант C — `variant-c-experimental`: социальный и продвинутый

**Миссия:** всё из B + вовлечение, контент и аналитика. Вечерняя лига, юниоры, клуб-маркетинг.

| # | Ключевая фича | Содержание |
|---|---|---|
| C1 | PWA+ | Установка, push-уведомления (смена лидера, завершение матча, подтверждение карты) |
| C2 | Соцфичи | Реакции, комментарии, чествование (highlight игрока), фото моментов, шеринг карточек |
| C3 | Статистика игрока | История, тренды, лучшие лунки, распределение по парам, «точность» (попадание в пар) |
| C4 | Аналитика турнира | Heatmap сложности лунок, пейсинг поля, средний счёт по лункам |
| C5 | Auto-commentary | Live-триггеры: «игл на 7-й», «лидер сменился», «двойной боги у лидера» — в live-фид и push |
| C6 | Мультиустройство и брендинг | Скоринг на телефоне + лидерборд на планшете + админка на ноуте (роли устройств не конфликтуют); кастомизация тем клубом |

**Риски:** соцфичи раздувают бандл и NFR-бюджеты (лечится: всё C2–C5 — ленивые чанки, деградация до B при слабой сети); модерация контента (решается: комментарии только внутри турнира, удаление админом, без публичных лент).
**Отличие:** единственный с контентным/социальным слоем; лучший для вовлечения.
**Целевой сценарий:** вечерняя ночная лига; корпоратив с активными зрителями; юниорский фестиваль.

## Приоритизация сборок (3×5)

| Приоритет | Сборка | Почему |
|---|---|---|
| 1 | **A×1** (core × classic) | Эталон надёжности, база реальной игры |
| 2 | **A×3** (core × modern sport) | Контрастный дизайн на надёжной базе |
| 3 | **B×2** (tournament × broadcast) | Полный турнир в стиле трансляции |
| 4 | **C×5** (experimental × night round) | Вечерняя игра с соцфичами |
| 5 | Остальные 11 | По мере ресурсов, с фиксацией отклонений |

Приоритетные сборки доводятся до **полного соответствия NFR.md и расширенного чек-листа**; остальные — до обязательного минимума с явным списком отклонений в PR.
