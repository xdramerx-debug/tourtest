## 1. Stroke Play (A)

- **Подсчёт:** сумма ударов (гросс) / гросс − PH (нетто). Multi-round — сумма по раундам.
- **Победитель:** меньший итог; зачёты гросс и нетто могут вестись параллельно (настройка).
- **Ничьи:** countback (RULES §9) или playoff — настройка.
- **Ограничения:** до 144 игроков (NFR), 1–4 раунда.
- **Настройки:** allowance (обычно 0.95 для индивидуального stroke), cap Net Double Bogey (вкл по умолчанию), раздельные зачёты гросс/нетто, флайты.

## 2. Stableford (A)

- **Подсчёт:** очки по RULES §5.1 от нетто ли лунках (удары по SI от PH).
- **Победитель:** больше очков. **Ничьи:** countback по очкам последних 9/6/3/1.
- **Настройки:** allowance 1.0 по умолчанию (рекомендация WHS для stableford), pickup=0 автоматически, стартовая «полка» очков — нет (out).
- **Modified:** настройка 6 значений таблицы (альбатрос…двойной), пресеты §RULES 5.2.

## 3. Match Play — singles (B)

- **Подсчёт:** статусы RULES §6; счёт в ударах вводится как обычно, зачёт — по лункам.
- **Победитель:** выигравший матч (N up / N&M). Турнирная сетка (плей-офф круговую/олимпийку) — настройка: round-robin группы или single-elimination до 64.
- **Ничья матча:** §RULES 6.5 (делёж / саддн-дет список лунок / по последним N).
- **Настройки:** allowance (по умолчанию 1.0 back-low), concede включён, неотыгранные лунки после закрытия — без счёта.
- **Ограничения:** матч привязан к раунду; один игрок — один матч в раунде.

## 4. Fourball — better ball match (B)

- **Подсчёт:** пара против пары; на лунке сравниваются лучшие нетто каждой стороны; удары по allowance 0.9 от нижнего PH четвёрки (рекомендация WHS), настройка.
- **Победитель/ничьи:** как в match play. Статус матча общий для пары.
- **Настройки:** allowance, concede, «лунка вдвоём» (один партнёр может не доигрывать).

## 5. Foursome — alternate shot (B)

- **Подсчёт:** пара играет один мяч по очереди; ввод — один счёт на пару (любой из партнёров/капитан), чередование ударов системой не проверяется (фиксируется примечанием при споре — судья).
- **Формат зачёта:** match (по умолчанию, allowance = ½ суммы CH пары, рекомендация WHS) или stroke (PH пары = round(½ суммы CH)).
- **Настройки:** match|stroke, allowance формула.
- **Ограничения:** ровно 2 в команде.

## 6. Scramble (B)

- **Подсчёт:** команда 2–4 играет из лучшей позиции; один командный счёт на лунку. Ввод — капитан: счёт + «чей мяч выбран» (captain's pick, справочно/статистика).
- **Победитель:** меньший командный итог (гросс) или с командным гандикапом: `PH_team = Σ(CH_i × w_i)`; веса по умолчанию WHS-подобные: 2 игрока 0.35/0.15; 3 — 0.30/0.20/0.10; 4 — 0.25/0.20/0.15/0.10 (настраивается).
- **Ничьи:** countback по командному счёту.
- **Настройки:** размер команды, веса гандикапа, минимальное число выбранных мячей каждого игрока (например ≥3 на раунд — настройка, контроль отчётом).
- **Ограничения:** 1 счёт/лунка/команда; индивидуальные зачёты не ведутся.

## 7. Best Ball — командный stroke (B)

- **Подсчёт:** каждый играет свой мяч; на лунке в зачёт команды — лучший нетто из 3–4 (настройка: 1 лучший или 2 лучших мяча).
- **Победитель:** меньшая командная сумма.
- **Настройки:** N лучших (1|2), allowance 0.85 (рекомендация WHS для 4-person best ball), pickup разрешён, если партнёр уже обеспечил лучший мяч.
- **Отличие от Better Ball:** Best Ball — команда 3–4 и турнир команд; Better Ball — пары и зачёт пар/поля.

## 8. Better Ball — парный stroke (B)

- **Подсчёт:** пара: зачёт лучшего нетто на лунке; позиции — по сумме лучших мячей.
- **Победитель:** меньший итог. **Ничьи:** countback лучших мячей.
- **Настройки:** allowance 0.85, раздельный показ индивидуальных счетов (по умолчанию вкл).

## 9. Skins (B)

- **Подсчёт:** pot по лункам (значение очков/единиц, без денег — out of scope платежей); скин выигрывает единственный лучший нетто (или гросс — настройка) на лунке; равенство лучших → **carryover** на следующую лунку; неразыгранный carryover после последней — делёж/по настройке.
- **Победитель:** больше скинов (затем — больше единиц pot).
- **Настройки:** net|gross, pot по лункам (равный/возрастающий), carryover вкл/выкл, совместимость с флайтами.
- **Ограничения:** 2–8 игроков в скин-игре (иначе теряется смысл — предупреждение админу).

## 10. Team Aggregate (B)

- **Подсчёт:** команда 3–4; итог = сумма N лучших нетто каждого раунда (например, 2 из 4).
- **Победитель:** меньшая сумма. **Ничьи:** countback по командным дням.
- **Настройки:** N лучших, allowance 1.0, суммирование по раундам.

## Матрица тестовых сценариев (минимум 8, обязательна в Фазе 1)

1. Stableford: pickup на лунке → 0 очков, Thru продвигается.
2. Stroke net с плюсовым гандикапом: снятие ударов SI 18→17.
3. Match play: dormie, закрытие 3&2, carryover денег нет — статус корректен на каждой лунке.
4. Fourball: лучший мяч пары при concede лунки одному игроку.
5. Scramble: командный PH по весам 4 игроков; captain's picks ≥3 контролированы отчётом.
6. Skins: 3 carryover подряд, разыгрыш на 16-й, неразыгранный остаток — делёж.
7. Team Aggregate 2-из-4 с ничьей → countback.
8. Foursome match: PH пары = ½ суммы CH, статусы матча.
9. Equal-ничья stroke play → countback 9/6/3/1 → T.
10. DQ в 2-м раунде multi-round: исключение из общего зачёта, сохранение 1-го раунда в архиве.
