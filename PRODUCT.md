## 1. Что это

**ClubScore Live** (рабочее имя) — высокотехнологичный live-скоринг для гольфа для местного гольф-клуба с гибкими настройками. PWA/веб, без нативных приложений.

Продукт обязан:
1. Вести счёт в реальном времени во время раунда.
2. Показывать live-лидерборд игрокам, зрителям и админам клуба.
3. Поддерживать разные форматы игры, флайты, команды и раунды.
4. Гибко настраиваться под клуб, поле, турнир и правила — через UI админки, без правки кода.
5. Работать в полевых условиях: слабая связь, яркое солнце, перчатки, ввод одной рукой, раунды 4–5 часов.

Уровень: клубная система с претензией на высокотехнологичность. Не PGA Tour, не дворовая игра.

## 2. Аудитория и роли

| Роль | Кто это | Устройство / условия | Ключевые задачи |
|---|---|---|---|
| Игрок | Участник турнира, HI 0–54, возраст 12–80 | Свой телефон, поле, солнце, перчаток на левой руке, ввод правой | Ввести счёт ≤5 сек/лунка, видеть своё положение |
| Маркер | Игрок той же группы, ведёт счёт партнёра | Телефон, те же условия | Вести счёт 1–2 других игроков группы |
| Капитан | Капитан команды в командных форматах | Телефон/планшет | Состав, выбор мячей (scramble), командный счёт |
| Судья (referee) | Член комитета | Планшет/телефон | Правка счёта, штрафы, DQ/WD, разбор конфликтов |
| Зритель | Гости, члены клуба, родители, спонсоры | Свой телефон, экран клуба (TV) | Смотреть лидерборд, искать «своих» |
| Админ клуба | Менеджер турниров / гольф-оператор | Ноутбук/планшет, офис и поле | Создать турнир ≤5 мин, настроить поле ≤10 мин, править счёт, печатать отчёты |
| TV-экран | Безликий «зритель»: телевизор в клубе | 1080p+, автообновление, без сессии | Непрерывный показ лидерборда |

Принцип: одна кодовая база, разные сессии под разные роли; зритель не обязан регистрироваться.

## 3. Ключевые сценарии клуба

1. **Клубный чемпионат** — stroke play, 2–3 раунда, флайты по HI, нетто и гросс зачёты.
2. **Корпоративный выезд** — scramble/бest ball для смешанных уровней, много зрителей, спонсорский брендинг.
3. **Вечерняя/ночная игра** — 9 лунок, relaxed-атмосфера, тёмный экран важен.
4. **Детский/юниорский турнир** — 9 лунок, короткие ти, счёт вводит взрослый (маркер).
5. **Турнир выходного дня** — stableford, 1 раунд, быстрый старт, минимум админки.

## 4. North Star и ключевые метрики

**North Star:** 3 из 5 приоритетных сборок проходят полный расширенный чек-лист с первого раза, остальные 10 — со второго.

Ключевые метрики (методы измерения — в SUCCESS.md):
- Игрок вводит счёт на лунке за **≤5 секунд одной рукой**.
- Лидерборд обновляется у зрителей за **≤2 секунды** (p95, от приёма события сервером до рендера).
- Система выдерживает полный турнир на **144 игрока** без потери данных, в т.ч. при потере сети (RPO локального ввода = 0).

## 5. Анти-метрики (недопустимые исходы)

| Анти-метрика | Чем измеряем провал |
|---|---|
| «Красиво, но медленно» | Ввод счёта >5 с из-за анимаций; INP >200 мс на счётокарте |
| «Умно, но непонятно» | Правило/статус требует объяснения; >20% тестовых пользователей спрашивают «что это значит» |
| «Онлайн, но теряет данные» | Любой введённый счёт потерян при обрыве (edge-тесты USER_FLOWS) |
| «Гибко, но нерабочее» | Админ не смог создать турнир за 5 мин / настроить поле за 10 мин |
| «Много, но нерабочее» | Собирается <15 из 15 сборок |

## 6. Границы (OUT-OF-SCOPE)

- Нативные приложения iOS/Android — только PWA/веб.
- Платёжные интеграции и приём денег.
- Официальный WHS-рейтинг федерации — только локальный гандикап клуба (формулы WHS-совместимы, см. RULES.md §4, но без выгрузки в федерацию).
- Интеграция с Trackman/launch monitor.
- ТВ-продакшн уровня PGA Tour (графические движки, видео).

**Scope freeze:** после апрува 16 источников правды новый функционал/форматы/дизайны — только через апрув (см. REVIEW.md). Расширение scope вне этих файлов запрещено.

## 7. Продуктовые принципы (порядок важности)

1. **Точность счёта важнее красоты.** Любой дизайн, мешающий корректному счёту, проигрывает.
2. **Полевые условия — первоклассный гражданин.** Каждое решение проверяется вопросом: «а на солнце, в перчатке, без сети?»
3. **Ноль потерь данных.** Offline-first — не фича, а основание. Конфликт никогда не решается удалением чужого ввода без аудита.
4. **Одинаковая IA у всех 15 сборок.** Меняются функционал (ось 1) и стиль (ось 2), не структура.
5. **Настройка без кода.** Клуб, поле, турнир, правила — из админки.
6. **Простота для зрителя.** Лидерборд находится за ≤2 клика без регистрации.
7. **Меньше — надёжнее.** Декомпозиция вместо срезанных углов (см. ESTIMATE.md).

| D5 | Гандикап | Локальный HI + course/playing handicap по формулам WHS (упрощения перечислены в RULES.md §4.4) | Федеративный WHS — out of scope |

| D7 | Ветвление | Сессионная ветка фиксирована средой; роль `variant/*/design/*` выполняют **директории** `apps/variant-{a,b,c}/design-{1..5}`; фазы = PR из сессионной ветки | Ограничение среды исполнения; подтверждается человеком на апруве Фазы 0 |

## 9. Глоссарий (минимум; полные правила — RULES.md/FORMATS.md)

- **HI** — handicap index игрока (локальный). **CH/PH** — course/playing handicap.
- **SI** — stroke index лунки (1..18, сложность распределения ударов).
- **To par** — счёт относительно пара. **Thru** — сыграно лунок.
- **Флайт** — группировка игроков по HI внутри турнира.
- **DQ / WD / DNS** — дисквалифицирован / снялся / не вышел.
- **Dormie** — статус match play: лидер ведёт ровно на число оставшихся лунок.
- **Countback** — тай-брейк по последним 9/6/3/1 лункам.
