### Механика переключения (ARCHITECTURE §0 v2)
- Источники по приоритету: `?theme=N` → `localStorage.csl.theme` → системная тёмная → дефолт.
- Применение — только data-атрибуты `<html>` (`applyTheme` из @csl/tokens): CSS-переменные
  флипаются мгновенно; DOM/React-дерево не трогается; хранилища данных не пересоздаются.
- Переключатели: UI-пикер в topnav (с иконкой-свотчем каждой темы и подсказкой), горячие
  клавиши `Alt+T` (цикл) и `Alt+1..5` (прямой выбор), URL-параметр `?theme=N` (синхронится
  через `history.replaceState` — шарится ссылкой), сохранение в `csl.club.theme` профиля клуба.
- Анти-FOUC: inline-скрипт в `index.html` выставляет data-атрибуты до первого кадра.
- Системная тема: `prefers-color-scheme: dark` → Night Round как стартовый дефолт;
  светлая → Classic. Пользовательское переопределение всегда побеждает.

## 6. Честные остаточные ограничения / следующие шаги эксплуатации

1. Мульти-девайс реальной синхронизации в демо показан через DemoTransport (seed/реал-тайм внутри вкладки); боевой SSE — с поднятием `apps/server` (см. DEPLOY).
2. Push-уведомления (APNS/FCM) — вне scope демо (требуют платёж/учётки); интерфейсы заложены.
3. Профильная замерка «≤100 мс» переключения — инженерного уровня (низкоприоритетный тюнинг).
4. RTL — smoke-уровень; полный RTL-аудит — при появлении RTL-локали.
